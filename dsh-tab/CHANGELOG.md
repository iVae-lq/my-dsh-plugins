# Changelog

## Unreleased

- 子智能体 / 智能体团队成员的会话不再单开标签：官方会话目录里它们是 `origin: "subagent"` 的行，现在归到所属主会话的标签（沿 `parentId` / `subagentCatalog` 一路找到最上层的主会话）。在标签里点开子智能体，标签栏不新增、该标签保持选中；点已选中的主会话标签不会跳走。
- 每个标签记住自己最后停在的子智能体 / 团队成员（仅本次运行，不落盘）：切到别的标签再切回来，回到那个子会话（用官方绑定里的子会话地址，带 mode）；在会话里点「回到主会话」后则下次回主会话；子会话被删掉时回主会话。
- 关闭主会话标签时，如果正看着它的子智能体，按平时的规则落到相邻标签；旧版本给子智能体单开过的标签在升级后自动清掉。
- 新增客户端测试：`test/helpers/client-harness.mjs` 用极简 hook 宿主跑真实的 `client.js`，`test/client-subagent-tabs.test.mjs` 覆盖上面的行为。

## 0.2.0 — 2026-11-01

- npm 包名：`dsh-tab`，首次发布。
- 新增书页式会话标签栏：一个会话一个标签，点击切换会话不刷新页面。
- 新增工作区角标：每个标签左上角显示所属工作区（颜色由工作区 ID 哈希得到，悬停看全名）。
- 新增拖拽排序：同组内拖动标签调整顺序，松手即写入 `localStorage`。
- 新增固定 / 取消固定：固定标签排在最左、只显示图标。
- 新增右键菜单：关闭 / 关闭右侧 / 关闭其他 / 关闭全部 / 固定 / 归档会话。
- 新增状态点、`←` / `→` 键盘切换、中键关闭。
- 切换标签改为先跑 140ms 标签动画，再在 150ms 后切换会话内容，避免官方整页重渲染打断动画。
- 右栏全屏时标签栏隐藏并把帧首行归零，消除顶部 44px 空白。
- 关闭全部 / 关闭最后一个空白标签时保留当前空白页，避免标签栏空着或旧标签被异步加回。

## 0.1.0 — 2026-10

- 首个可用版本：标签栏、新建标签、关闭标签、归档会话、会话状态点、localStorage 持久化。
